# cailo-legal

The public Privacy Policy and Terms for the Cailo Android app, served by
GitHub Pages at `https://raees-yuuki.github.io/cailo-legal/`.

- `privacy.html` and `terms.html` are generated from the app's own legal
  screens, so the hosted text and the in-app text stay identical. Don't edit
  them by hand: change the app, then run

  ```
  python tools/build_from_app.py C:/apps/calc_sphere
  ```

- `index.html` links the two pages.
